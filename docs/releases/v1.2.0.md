# v1.2.0

發版文件日期：2026-04-28

`v1.2.0` 記錄 Phase D governance baseline freeze 與 runtime structural
enforcement v0.1。這份文件讓 repository 的 release reader、README 與
CHANGELOG 使用同一版本；文件就緒不等於 GitHub Release 或 tag 已發布。

## 主要內容

- Phase D close authority 由 `governance/PHASE_D_CLOSE_AUTHORITY.md` 定義。
- `phase_d_closeout_writer.py` 驗證 required conditions、verdict 與 reviewer
  metadata 的結構完整性。
- closeout failure semantics 區分 blocked、void 與 runtime-unverifiable。
- release/status readers 可由 `docs/releases/generated/` 與
  `docs/status/generated/` 取得 repo-local 產物入口。

## Supported AI Adapter Surfaces

- Claude Code
- Codex
- Gemini

Adapter 存在不代表所有 harness 或 consumer 都已接上同一 enforcement
層級；實際能力仍取決於 wiring、contract 與 evidence。

## Known Limits

- 這仍是 bounded prototype，不是 security boundary 或完整 policy engine。
- F12–F15 legitimacy failures 仍需要 reviewer attestation。
- F4 artifact immutability 與 F16/F17 exception authority path 尚未實作。
- 文件、bundle、checklist 與 CI reader 通過都不能證明 GitHub Release 或
  `v1.2.0` tag 已發布。
- `main` 的 Unreleased 變更不屬於 `v1.2.0` release scope。

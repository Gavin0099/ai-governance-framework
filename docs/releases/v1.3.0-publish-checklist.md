This checklist validates the `v1.3.0` release-facing files and generated
artifacts. Until every applicable item is checked, do not claim that a GitHub
Release or tag has been published.

## GitHub Publish

- [ ] Tag `v1.3.0` is created on the approved commit.
- [ ] GitHub Release body uses `v1.3.0-github-release.md`.
- [ ] Release URL and tag are verified by a read-only remote query.

## Required Claim Boundaries

- [ ] Bounded prototype / audit framework, not a security boundary.
- [ ] Release-facing files and CI readers do not prove remote publication.
- [ ] Consumer role boundaries, explicit response-envelope conflict limits, and
      reviewer-attested authority limits remain disclosed.

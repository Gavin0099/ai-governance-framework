# v1.3.0 GitHub Release Draft

`v1.3.0` is a release candidate for the F-7 consumer synchronization
boundary. This document is a draft only; it is not evidence that a remote
GitHub Release or tag exists.

## Highlights

- Added the v0.7 compact response-envelope policy to the F-7 managed
  instruction boundary.
- Added explicit version-conflict detection for legacy response-envelope
  markers.
- Added focused regression coverage for legacy conflicts and historical
  changelog text inside the current contract.
- Kept copy-based consumer behavior audit-only; automatic full-update claims
  remain limited to supported repo roles.

## Prototype Boundary

This remains a bounded prototype and audit framework, not a security boundary,
complete policy engine, or proof of AI semantic correctness. A passing focused
suite does not prove fleet adoption, consumer correctness, or release safety.
